# 四级、六级与雅思词库

## 使用

弹窗顶部的「词库」每次选一项：四级、六级或雅思。默认四级，选择保存在本机浏览器中，下次打开仍使用上次选择。

当前视频的单词、统计、历史记录中的词数与已斩词列表都按所选词库筛选。单词卡片和详情会展示全部命中标签，例如选择六级时，重叠词仍可同时显示「四级」「六级」「雅思」。搜索在当前词库中进行。

采集时保存三份词库的命中并集和完整标签；切换词库或学习模式直接使用已有采集结果。普通模式隐藏基础词及其变形，测试模式包含它们；原始记录始终保留。斩词记录由三个词库共享；清空所有斩词会清空三个词库的记录。

## 普通模式与测试模式

- **普通模式**沿用释义、单词详情、本地优先和在线补充查词；只隐藏基础词，不从采集或存储层删除。
- **测试模式**使用本地中文四选一题目，包含基础词，仍按当前选择的词库筛选。答错会标记选项；答对显示释义并完成本次题目，但不自动标记熟悉。用户仍可单独点「斩」，并在「已斩词」撤销。
- 题目按词形原型查找，例如 `studies` 显示在卡片上，题目使用 `study`。字幕词形、视频历史、词库选择和熟悉词由两种模式共享。
- 每词最多保留最早的 10 个不同字幕时间点，使用采集时已有精度。模式切换不会清空记录或时间。
- 测试题来自扩展内置数据，不会为生成选择题联网。点「详解」后才沿用普通模式的词典查询。
- 朗读只使用浏览器标记为本地服务的英语音色；没有可用本地英语音色时显示提示。

旧版本只采集四级词。读取旧记录时会为已保存的词补标签，不能恢复当时未保存的六级或雅思词。重新抓取并播放字幕可补充新词库的命中。

## 数据

| 选项 | 词数 | 来源 | 许可 | 本地释义 |
| --- | ---: | --- | --- | --- |
| 四级 | 4,590 | 项目原有 eeliu/english-vocabulary 数据与补充词 | 沿用原项目数据 | 原中文释义 |
| 六级 | 2,219 | [OpenEtymology CET6](https://github.com/openetymology/OpenEtymology/blob/7d89f3697abf26e305fe2627f181b692c2c10b28/CET6/CET6.txt) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) | 源词表没有释义 |

雅思选项是社区整理、含 AI 增补的 **TOEFL / IELTS 共用学术词表**，非官方雅思词表、非雅思专属，也不代表完整考试词汇范围。作者为 gungorkaya-eng / [WordLevel](https://wordlevel.net)。标签只代表命中内置学习词表。

相同词头的普通词表释义优先使用四级中文，其次使用共用学术词表英文。只有词头的六级词不会从题库释义回填普通模式词义，也不会在词性未知时推测变形；可点击「详解」使用原有联网词典。

题库覆盖三词库词头并集 6,043 词。上游题库原样保留 4,590 条四级题目；固定提交版本的 ECDICT 提供 1,452 个缺口词的中文释义。ECDICT 仓库声明 MIT，但其 README 说明这是多来源汇编，单词条没有保留上游出处；项目依据仓库级 MIT 声明复用，并公开记录这一溯源限制。程序按词性、释义去重和汉字重合比例整理干扰项，并对一个基础词性回退例外作记录。IELTS 中的历史词头 `inasmuchas` 是短语 `inasmuch as` 的连写；为兼容旧记录，保留旧词头并新增短语匹配。其中文释义按固定 Wiktionary 修订中的英文释义整理。

补充题为自动整理，尚未逐题人工语义审校；结构校验会检查唯一正确项、四个非重复选项、干扰项词头来源和词库覆盖，但这些检查不能代替人工判断。新增来源的许可、来源提交、获取日期、源/输出校验值、规则、覆盖和缺项见 [`quiz-sources.json`](../quiz-sources.json)；用户署名入口为 [题库与词表来源页面](../vocabulary-sources.html)。

## 归属与重建

- `cet6_words.json` 是 OpenEtymology CET6 的格式改编，数据继续使用 CC BY-SA 4.0；保留署名、来源及相同许可。
- `ielts_words.json` 保留 WordLevel 原数据的 MIT 版权和许可通知。
- 原始数据许可全文/声明在 `licenses/`，面向使用者的署名入口为弹窗「词表来源」（`vocabulary-sources.html`）。
- `vocabulary-sources.json` 记录固定提交、源 SHA-256、整理文件 SHA-256、条目数、提取字段及改动。采集日期为 2026-10-10。
- `scripts/import-vocabularies.py` 使用 Python 3 标准库重建新增词表；下载固定源版本，先校验源哈希，再转小写、排序和生成 JSON。扩展运行时不调用该脚本，不下载词表。
- `scripts/build-quiz-extras.py` 使用固定 ECDICT 提交和 Wiktionary 修订生成补充题；会核对源文件校验值。`scripts/validate-quiz-data.py` 检查三词库题目覆盖、选项结构、来源文件和输出校验值。

## 更新扩展

在 `chrome://extensions/` 或 `edge://extensions/` 点本扩展的重新加载按钮，再刷新视频页面并打开弹窗，即可看到顶部词库和学习模式选择器。已有采集记录和斩词数据保留；首次使用默认普通模式。
