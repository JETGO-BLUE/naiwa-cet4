# 商店截图

## 现在这里有什么

落地页（`docs/index.html` 的「界面预览」）用的三张图，已就位：

| 文件名 | 内容 | 实际尺寸 |
|--------|------|----------|
| `01-word-list.png` | 当前视频 · 单词列表（时间点 / 出现次数） | 431×594 |
| `02-word-detail.png` | 点击单词 · 变形与各词性释义 | 391×462 |
| `03-familiar-words.png` | 已斩词 · 熟悉的词不再打扰 | 427×302 |

首页会给每张图一个**等高 310px 的显示框** + `object-fit: contain`（等比缩放、不裁不拉），
所以三张比例差得比较多也不会变形，卡片高度是对齐的。

## ⚠️ 商店提交还需要另外做一套 1280×800

上面这三张是**从截屏里裁出来的弹窗本身**，尺寸达不到商店要求。
Chrome 应用商店和 Edge 加载项都要求截图 **1280×800**（或 640×400）。

做法：

1. 打开一个带字幕的视频，让视频播一会儿（攒够单词）
2. 用 `Win + Shift + S` 截取**视频画面 + 扩展弹窗同框**的效果
   —— 商店更想看到「扩展在真实页面里长什么样」，纯弹窗截图的通过率不如同框图
3. 裁成 16:10（1280×800）再上传；每个商店至少 1–2 张，最多 5 张

## 想换首页的图

直接把同名文件覆盖掉，刷新页面即可。

> 文件名对不上也不会报错 —— 首页脚本会把破图换成「截图待补充」的占位块。
