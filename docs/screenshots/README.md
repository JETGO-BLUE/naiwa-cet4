# 商店截图放这里

把截图命名为下面这几个名字放进来，`docs/index.html` 的「界面预览」会自动显示：

| 文件名 | 内容 | 要求 |
|--------|------|------|
| `01-word-list.png` | 单词列表（带时间点、出现次数） | 1280×800 |
| `02-word-detail.png` | 点击单词后的详情（原型 / 变形 / 释义） | 1280×800 |
| `03-familiar-words.png` | 已斩词页面 | 1280×800 |

## 怎么截

1. 打开一个带字幕的视频，让视频播一会儿（攒够单词）
2. 用系统截图工具（Win + Shift + S）截取**扩展弹窗 + 视频画面同框**的效果最好
3. Chrome 应用商店要求截图尺寸 **1280×800**，可以用图片工具裁剪缩放
4. 建议每个商店至少传 1–2 张，最多 5 张

> 如果文件名对不上，首页会显示占位方块（不会报错），补齐后刷新即可。
