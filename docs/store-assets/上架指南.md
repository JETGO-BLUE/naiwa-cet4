# 奶娃过四级 · 双平台上架指南

目标平台：**Chrome 应用商店（Chrome Web Store）** + **Edge 加载项（Microsoft Edge Add-ons）**
同一份 zip 包，两边独立提交、独立审核。

---

## 一、先看结论：成本与时间

| 项目 | Chrome Web Store | Edge Add-ons |
|------|------------------|--------------|
| 开发者账号费用 | **5 美元一次性**（要国际信用卡/PayPal） | **免费** |
| 注册入口 | `chrome.google.com/webstore/devconsole` | `partner.microsoft.com`（用 Microsoft 账号） |
| 审核时长 | 新提交 2–3 个工作日；更新 1–2 天 | 最多 **7 个工作日**（通常更快的也有） |
| 包格式 | .zip（就是我们那个 zip） | 同一个 .zip |

> ⚠️ Chrome 那 5 美元是**唯一花钱的地方**，而且需要能支付的国际卡（国内双币卡一般可以，纯银联不行）。

## 二、动手前必须先解决的一件事：权限范围

**这是最可能被拒的地方，重点看。**

现在 manifest 里写着：

```json
"host_permissions": ["http://*/*", "https://*/*"],
"content_scripts": [{ "matches": ["http://*/*", "https://*/*"] }]
```

翻译成人话就是：**这个扩展要在你访问的所有网站上跑**。审核员看到这句第一反应是"你想干嘛？"。

**两个选择：**

- **A. 收窄到视频网站白名单**（推荐，过审率高很多）
  ```json
  "matches": [
    "https://www.youtube.com/*",
    "https://www.netflix.com/*",
    "https://www.bilibili.com/*",
    "https://www.coursera.org/*",
    "https://www.udemy.com/*",
    "https://www.ted.com/*",
    "https://vimeo.com/*",
    "https://www.disneyplus.com/*",
    "https://www.primevideo.com/*"
  ]
  ```
  ⚠️ 代价：只有清单里的网站能用。沉浸式翻译支持 100+ 平台，收窄后你在小众平台看视频就抓不到词了。

- **B. 保持全站，但把理由写足**（过审率低一些，但你功能最全）
  在隐私说明里写清楚：*本扩展需要读取页面字幕 DOM 以提取英文单词；沉浸式翻译的双语字幕可能出现在任意视频网站上，因此需要广泛的主机权限。扩展不上传任何网页内容，仅将用户主动点击的单个单词发送至公开词典 API 查询释义。*

> 我的建议：**先按 A 提交**（好过），等上架稳定了，再发一个 B 版本扩权限（更新时说明理由）。

## 三、需要准备的材料清单

### 图片（我已生成，放在 `store-assets/`）

| 素材 | 尺寸 | 用在哪 | 状态 |
|------|------|--------|------|
| 扩展图标 | 128×128 | 包内，Chrome 商店显示 | ✅ 已有（icons/icon128.png） |
| 商店 Logo | 300×300 | Edge 商店显示 | ✅ `store-logo-300.png` |
| 小型宣传图块 | 440×280 | Chrome 商店 | ✅ `promo-440x280.png` |
| 顶部宣传图块 | 1400×560 | Chrome 商店 | ✅ `promo-1400x560.png` |
| **截图** | 1280×800 或 640×400 | 两个商店都要，至少 1 张 | ❌ **只能你自己截** |

**截图怎么截**：打开一个开着双语字幕的 YouTube 视频 → 点扩展图标 → 按 `Win + Shift + S` 截图 → 或者直接 `Win + PrtSc`，然后用画图裁成 1280×800。建议截 3 张：
1. 弹窗的单词列表（带时间点）
2. 点开某个单词的详情（单词变形 + 各词性释义）
3. 已斩词 / 历史记录页

### 隐私政策（必须，因为用了第三方 API）

需要放到一个**公开可访问的网址**上。三种方案：

| 方案 | 优点 | 缺点 |
|------|------|------|
| **腾讯文档** 公开分享链接 | 你在国内访问顺畅 | 国外审核员打开可能慢 |
| **GitHub Pages** | 审核员最熟悉、最稳 | 国内访问 GitHub 偶尔抽风 |
| **Google Sites** | 谷歌自家产品，审核友好 | 国内打不开（但你只用它提交，不影响） |

> 内容我已写好：见 `隐私政策.md`，直接复制粘贴到上面任一平台即可。

### 商店文案（中英双语）

内容见 `商店文案.md`。Chrome 支持多语言列表，Edge 要按语言分别填。中英都给审核员准备好了，省得他们看不懂中文描述直接拒。

## 四、Chrome Web Store 提交步骤

1. 打开 `chrome.google.com/webstore/devconsole`，用 Google 账号登录
2. 付 **5 美元** 注册开发者（一次性，以后上架多少个都不用再付）
3. 点 **「新增项目」** → 上传 `yt-cet4-extension.zip`
4. 填 **「商品详情」**：
   - 名称 / 简介（用 `商店文案.md` 里的）
   - 类别：**生产工具** 或 **教育**
   - 语言：中文（简体）+ 英文
   - 上传商店图标 128×128、截图、宣传图块
5. 填 **「隐私权规范」**（这一步最容易卡住）：
   - **单一用途说明**：一句话讲清这扩展只干一件事
   - **权限理由**：逐个解释 `storage` / `tabs` / `主机权限` 为什么要用
   - **数据使用**：勾选"不收集用户数据"，但**必须声明**会把单词发送给第三方词典 API
   - **隐私政策网址**：填你上面放的那个链接
6. 填 **「分发范围」**：公开 / 不公开（先不公开测试也行）
7. 提交审核 → 等 2–3 天

## 五、Edge Add-ons 提交步骤

1. 打开 `partner.microsoft.com`，用 **Microsoft 账号**登录（免费注册）
2. 进入 **Edge 卡片** → 「创建新扩展」
3. 上传同一个 `yt-cet4-extension.zip`
4. **可用性**：公开 / 隐藏；选择上架市场（可先只选中国 + 美国）
5. **属性**：类别、支持邮箱、隐私政策网址
6. **隐私信息**：说明用途、为每个权限辩护、声明是否用远程代码（我们没有）、设置隐私策略
7. **商店一览**：每种语言填显示名、描述（250–5000 字符）、logo 300×300、截图
8. **认证测试说明**：告诉测试员怎么验证（重要！见下）
9. 提交 → 等最多 7 个工作日

### 认证测试说明建议这样写

```
测试步骤：
1. 安装本扩展
2. 安装「沉浸式翻译」扩展并开启 YouTube 双语字幕
3. 打开任意带字幕的英文视频，播放 30 秒以上
4. 点击本扩展图标，可看到收集到的四级词汇及出现时间点
5. 点击任意单词可查看词形变化与释义
6. 点击「斩」可标记熟悉词

所需账号：无（不需要登录任何账号）
说明：本扩展仅在本地处理字幕文本，不上传页面内容。
```

## 六、可能被拒的原因（提前避坑）

| 风险 | 说明 | 对策 |
|------|------|------|
| **权限过宽** | 全站 host 权限 | 见第二节，收窄或写足理由 |
| **缺隐私政策** | 用了第三方 API 就必须有 | 用 `隐私政策.md` |
| **单一用途不明确** | 描述含糊 | 一句话讲清"收集视频字幕中的四级词汇" |
| **描述与实际不符** | 宣传了没有的功能 | 文案只写真实功能 |
| **图标/素材侵权** | ⚠️ **见下** | — |

### ⚠️ 关于"奶娃"这个形象，我必须提醒你

这图**来源不明**（很可能是 AI 生成或网络 meme），版权状态不清楚。用它做图标：
- **审核员大概率不会查**，能过；
- 但**万一**原作者/权利方投诉，商店会直接下架，还可能牵连你的开发者账号。

你是对风险敏感的人，所以我把话说到：**想长期做，最好换成自己画的/明确可商用的形象**。或者找一张 CC0 授权的表情素材。现在这样上架，"能用"但"有雷"。

## 七、上架后

- **更新版本**：改 `manifest.json` 里的 `"version"`，重新打包 zip，再传一次，等审核
- **两边独立**：Chrome 和 Edge 各有各的版本号、审核时间、用户群，互不影响
- **用户量**：Chrome 商店后台能看到装机量、评分

1. ✅ 素材已备（`store-assets/`）
