奶娃过四级 · 数据来源、许可与校验值

三、题目的干扰项从哪来

四级题的 3 个干扰释义来自 quiz_bank.json：由四级词表离线计算， 按「形近 / 同词性 / 易混淆」挑选，并做了释义级去重，避免"两个选项都对"。 题库覆盖全部 4,590 个四级词，出题和判分全程在本机，不联网。

六级 / 雅思词若不在四级词表内，出题时从合并后的释义池里现场挑干扰项， 挑法和四级一致（词性相同优先、汉字重合度低的优先）。

五、复现

python scripts/build-vocab-data.py \
    --fetch \
    --extras quiz_extras.json

脚本会先校验源文件的 SHA-256（不一致直接退出），再生成三个数据文件， 最后把来源、条目数和输出哈希写回 vocabulary-sources.json。 扩展运行时不会调用这个脚本，也不下载任何词表。
