奶娃过四级

看视频的时候，把四级词汇悄悄攒起来 —— 自动抓取字幕里的 CET-4 单词，每 3 分钟标时间点、四选一记词、查变形、一键斩掉熟悉词。

📦 安装使用 🔒 隐私政策

你每天刷的视频，其实藏着大量四级词汇

可惜看完就忘，一个都没留下。这个扩展帮你把它们捞出来。

🎯

自动抓词

播放视频时自动从字幕提取四级词汇。优先读取「沉浸式翻译」的双语字幕，没开也能抓 YouTube 原生字幕。

⏱️

每 3 分钟记一次时间点

同一个词在 3 分钟区间内出现多少次都只记一次（0:00 / 3:00 / 6:00…），最多 10 个 —— 能定位原句，又不会把列表刷满。

🎧

四选一记词

不直接给中文释义：单击单词听发音，再从 4 个中文释义里选。选错标 ❌，选对才亮出答案。4590 词的题库全在本机，出题不联网。

🗡️

一键「斩」

认识？点一下「斩」，这个词立刻从列表里消失。越用越清爽，专注那些你还不熟的词。

📖

点「详解」看全貌

单词变形（复数 / 过去式 / 过去分词 / 现在分词 / 比较级 / 最高级）本地秒出，各词性释义只留常用的。

🔍

双词典兜底

本地词表 → Free Dictionary API → Wiktionary，遇到 404 也能查到词条。

🌐

不局限于 YouTube

纯只读监听页面字幕元素，不修改页面、不影响翻译扩展、不影响你看视频。

界面预览

安装使用

扩展还在开发者模式下加载（商店审核中），跟着下面做，五分钟搞定。

必读：一定要打开「沉浸式翻译」的双语字幕 本扩展抓的词，就是从「沉浸式翻译」渲染出的双语字幕里取的（只取英文原文那一行）。 不开的话，除了 YouTube 自带字幕，Netflix / B站 这类平台基本抓不到词 —— 想省事就一直开着。
  1. 下载源码 在 GitHub 仓库页面点 Code → Download ZIP，解压到任意目录。
  2. 打开扩展管理页 Chrome 访问 chrome://extensions/；Edge 访问 edge://extensions/。
  3. 开启开发者模式并加载 打开右上角（Edge 为左下角）的「开发者模式」，点「加载已解压的扩展程序」，选择含 manifest.json 的那一层目录。
  4. 打开「沉浸式翻译」的双语字幕 在视频页打开沉浸式翻译（应用商店搜 Immersive Translate，免费），让画面上出现英文 + 中文两行字幕。这步别跳过 —— 它决定了能不能抓到词。
  5. 让视频播起来，再看弹窗 单词是跟着播放进度一句句累积的，只打开不播不会有东西。播 30 秒左右，点工具栏里的奶娃图标，词就出来了。

🔒 隐私优先

  • ✅ 字幕文本只在你的浏览器本地处理，不上传（我们根本没有服务器）
  • ✅ 只有你主动点击单词时，才把那个单词本身发给公开词典接口
  • ✅ 「已斩词」和收集记录保存在浏览器本地，不离开你的设备
  • ✅ 无需登录、无广告、无追踪、无统计分析
