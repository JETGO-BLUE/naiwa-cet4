# 奶娃过四级 · 安装 & 使用说明

一个 Chrome/Edge 扩展，读取字幕里的**四级、六级和雅思学习词汇**（沉浸式翻译英文原文、可读取的标准英文字幕轨，以及 YouTube 原生字幕兜底），单选词库、展示全部命中标签、去重、标注出现时间点，还能「斩」掉熟悉词。

界面会自动隐藏冠词、代词、介词、连词以及 `be`、`go`、`have`、`do` 等常见基础词和它们的变形。原始采集记录仍保存在浏览器本地。

---

## 一、安装（3 步）

**Chrome 111+**：地址栏输入 `chrome://extensions/` 回车
**Microsoft Edge 111+**：地址栏输入 `edge://extensions/` 回车（基于兼容版本的 Chromium）

1. 打开上面的扩展管理页
2. 打开 **「开发者模式」** 开关（Chrome 在右上角，Edge 在左下角）
3. 点 **「加载已解压的扩展程序」**，选中这个文件夹：
   ```
   D:\字幕练单词
   ```

装好后工具栏会出现**奶娃头像**图标（扩展名：奶娃过四级）。

> ⚠️ 因为权限覆盖所有网站，加载或更新后浏览器可能提示"已更改权限"，点扩展卡片上的**刷新**按钮即可。
> Chrome 和 Edge 可以同时装同一份，但两边的「已斩词」数据**各自独立**、不互通。

## 二、怎么用

1. 打开有英文字幕的视频。沉浸式翻译显示英文原文、页面提供可读的标准英文字幕轨时可实时增量采集；YouTube 还支持原生字幕整轨兜底。
2. 正常播放时，本扩展只处理新出现或修订的字幕，边看边自动累积词卡和时间点。
3. 点工具栏图标，在顶部「词库」选择 **四级 / 六级 / 雅思**，一次选一个。默认四级，会记住上次选择。每个词显示**全部命中标签**与出现的**时间点**（通常为 mm:ss，字幕轨可精确到 0.1 秒；最多前 10 个）
4. 看到熟悉的词，点右边的 **「斩」** → 词卡变灰并计入已斩，三个词库共享熟悉词记录
5. **左键单击单词** → 弹出详情（两阶段加载，本地内容秒出）：
   - **本地词表释义**：重叠词优先用已有四级中文释义，其次用学术词表英文释义。仅有词头的六级词可联网查词
   - **单词变形**：复数 / 第三人称单数 / 过去式 / 过去分词 / 现在分词 / 比较级 / 最高级——**本地计算，秒出**，含约 100 个不规则动词 + 40 个不规则名词复数 + 不规则比较级
   - **各词性释义**：联网查询（主词典 4 秒超时 → 自动切 Wiktionary 兜底）；没有本地词性和释义的词不推测变形
   - **同根词**（内置三份词表内）

> YouTube 原生字幕兜底会从 YouTube 请求**整条英文字幕轨**，所以可能提前收集尚未播放部分的词。它不同于随播放进度进行的增量采集。扩展不会上传字幕到自有服务器。

### 同一视频累加与重新抓取

- 同一个可确认的 YouTube 视频会继续使用本地记录；刷新页面、关闭后重开弹窗或重新打开视频，已保存的词卡和时间点仍保留，新字幕只会追加或补充时间点。
- 同一视频开在多个标签页时，结果会合并保存。存储成功后才会确认对应字幕；页面还在时，未确认字幕会自动重发。浏览器和页面同时突然关闭前最后一小段未确认输入可能丢失。
- 对无法确认身份的非 YouTube 页面，本次页面连接会独立建档并标记“视频身份未确认”。刷新或重开后仍可从历史查看已保存记录，但不会盲目自动合并；同一视频可能出现多份历史记录。旧版非 YouTube 路径记录仍留在历史中。
- 点击「重新抓取」只重新连接字幕来源，不清空已有记录。弹窗状态区会区分连接、等待字幕、保存失败、没有可读字幕和字幕已采到但没有新增命中词。
- 本地合并保存通常等待约 500 ms，连续输入最长约 1 秒后发起写入；浏览器完成存储所需时间另计。

## 三、界面说明

| 标签页 | 作用 |
|--------|------|
| **当前视频** | 当前所选词库的单词 + 时间点，可搜索、可斩词；弹窗打开期间会自动更新且尽量保留滚动与搜索 |
| **历史记录** | 按所选词库显示每个视频的命中词数，点进去回看 |
| **已斩词** | 所选词库中的熟悉词，可撤销；「清空所有斩词」会清空三个词库共享的全部记录 |

采集时保存三个词库命中的并集，切换无需重新抓取。旧记录只收集过四级词，能给已有词补标签，但未保存的新词需要重新抓取并播放字幕来补充。

## 四、几个要点（务必看）

1. **沉浸式翻译通道**：只读 `#immersive-translate-caption-window` Shadow DOM 中的英文原文行，不改 DOM。容器或 Shadow DOM 重建后会重新连接；closed Shadow DOM 无法读取。
2. **标准字幕轨**：页面提供 `video.textTracks` 中已启用且可读的英文轨时，扩展监听 `cuechange`。不同站点暴露字幕轨的方式不同，无法保证每个站点都支持。
3. **YouTube 原生字幕**：只在 YouTube 页面通过内置 MAIN world 桥接读取播放器字幕轨元数据，再由扩展请求字幕轨。此兜底读取整条字幕，可能包含尚未播放部分。YouTube 播放器或字幕接口变化仍可能影响兼容性。
4. **实时增量与持久累加**：沉浸式翻译和标准字幕轨按新句采集。YouTube 同一视频按稳定视频 ID 合并旧词和新词；其余身份不确定的页面独立保存，不按同路径自动归并。
5. **斩词是全局的**：斩掉一个词，以后所有视频和词库里它都会标记为熟悉。想恢复去「已斩词」标签页点 ✕。
6. **时间点最多 10 个**：每个词只保留前 10 个不同时间点，不代表全量出现次数统计。标准字幕轨时间精确到 0.1 秒，DOM 字幕按采集时的播放秒数近似记录。
7. **词形还原**：`studies`/`studying`/`studied` 会匹配到词根 `study`，列表按小写字幕词形显示；不同词形仍分别显示。

## 六、显示「未捕获/没产出」？按这个顺序排查

1. **扩展刷新过没**：改完代码必须去 `chrome://extensions/` 点扩展的**刷新**按钮。
2. **页面刷新过没**：content script 是页面加载时注入的——改了扩展代码后，**正在看的视频页要 F5 刷新一次**，不然跑的还是旧脚本（新装扩展同理：先装再开页面，或者开了页面后刷新）。
3. **字幕来源是否可读**：沉浸式翻译需显示英文原文；标准轨需在页面可读取且启用；YouTube 原生兜底只找英文字幕。
4. **视频是否播放**：实时通道随字幕事件采集。YouTube 整轨兜底即使不播放也可能导入完整轨道。
5. popup 会直接告诉你卡在哪一步：
   - **「脚本没在这个页面跑起来」**→ 就是第 2 步，刷新页面
   - **「脚本已连接，等待可读取的英文字幕」**→ 检查第 3 步；容器晚出现时会继续低频检查
   - **「保存失败」**→ 页面会保留未确认输入；检查扩展本地存储后点「重新抓取」重试

## 五、词表来源

内置 **4590 个四级词汇**（含中文释义），来源：
1. 开源词库 `github.com/eeliu/english-vocabulary` 的「四级-乱序」表（4538 词，进阶核心词）
2. 手动补充 52 个基础高频词（`study`/`run`/`take`/`write` 等四级必考但原表剔除的基础词）

如果你想要更全的词表，可以自行替换 `cet4_words.json`（格式：`{"word": "释义", ...}`），改完在 `chrome://extensions/` 里点扩展的「刷新」按钮。

新增六级词表 **2,219 词** 来自 OpenEtymology（CC BY-SA 4.0）；雅思选项 **1,000 词** 来自 WordLevel（MIT），是社区整理、含 AI 增补的 **TOEFL / IELTS 共用学术词表，非官方、非雅思专属**。详细来源、固定版本、校验值和原数据许可见 [词库说明](词库说明.md) 或扩展顶部「词表来源」。

**联网查词**：点击单词时调用 [Free Dictionary API](https://dictionaryapi.dev/)（免费、无需 key）获取音标、多词性释义、例句、同反义词。需要联网。

## 六、隐私与网络请求

- 字幕在本地处理，只保存词卡、时间点及必要的去重状态，不把原始字幕作为长期记录保存。
- YouTube 原生字幕兜底会直接向 YouTube 请求所选字幕轨；该请求可能下载整条轨道。标准字幕轨和沉浸式翻译文本不另行上传。
- 点击单词查释义时，扩展会请求 Free Dictionary API，失败或无结果时再请求 Wiktionary；查询词会出现在请求地址中。
- 词卡、熟悉词、历史记录和未保存输入缓存均在本地；不发送使用统计或遥测。与浏览器同时关闭的最后一段未确认输入不保证恢复。

## 七、已知限制

- 只支持 **字幕**，不支持纯语音识别（语音转文字需要联网 API + 付费，暂不做）。
- 时间点为**文字**展示（mm:ss），不做点击跳转（按你的要求）。
- 低频连接检查会持续到字幕容器出现，因此超过 60 秒才出现的字幕仍可能被接入；来源本身无法读取时需要改用其他字幕通道。
- YouTube 原生兜底依赖播放器公开字幕轨元数据和 `json3` 字幕响应，接口变化需要重新验证。
