# 奶娃过四级 · 安装 & 使用说明

一个 Chrome/Edge 扩展，抓取视频字幕里的**四级词汇**（优先读取「沉浸式翻译」的双语字幕），去重、**每个 3 分钟区间**记录一个**精确出现时间点**（点一下就能跳回视频那一句），用**卡片式四选一**帮你把词记牢（答对自动翻下一题，可点读发音），还能把熟悉的词一键「斩」掉。

> **⚠️ 必读：一定要打开「沉浸式翻译」的双语字幕。**
> 本扩展抓的词，就是从「沉浸式翻译」渲染出的双语字幕里取的（只取英文原文那一行）。
> 不开的话，除了 YouTube 自带字幕，**Netflix / B站 这类平台基本抓不到词** —— 想省事就一直开着。
> 「沉浸式翻译」是另一个免费扩展（应用商店搜 `Immersive Translate`），它把字幕显示成"英文一行、中文一行"。

---

## 一、安装（3 步）

**Chrome**：地址栏输入 `chrome://extensions/` 回车
**Edge**：地址栏输入 `edge://extensions/` 回车（同一份代码，Edge 直接可用，无需改动）

1. 打开上面的扩展管理页
2. 打开 **「开发者模式」** 开关（Chrome 在右上角，Edge 在左下角）
3. 点 **「加载已解压的扩展程序」**，选中你解压出来的那个文件夹 —— **要选到「含 `manifest.json` 的那一层」**，不要选它的上一层

装好后工具栏会出现**奶娃头像**图标（扩展名：奶娃过四级）。

> ⚠️ 因为权限覆盖所有网站，加载或更新后浏览器可能提示"已更改权限"，点扩展卡片上的**刷新**按钮即可。
> Chrome 和 Edge 可以同时装同一份，但两边的「已斩词」数据**各自独立**、不互通。

## 二、怎么用

1. 打开任意一个**有字幕**的视频（YouTube / Netflix / B站等），并**打开「沉浸式翻译」的双语字幕** —— 画面上要能看到英文一行、中文一行
2. 让视频播放，双语字幕一句句出现时，本扩展会**边看边自动累积**单词
3. 点工具栏的 📚 图标查看已收集的四级词汇。界面是**卡片牌堆**：一屏只有一道题，一道一道往下做

### 一张卡片上有什么

| 位置 | 内容 |
|------|------|
| 左上 | **单词本身**（字号最大）+ 原型提示；单击可听发音 |
| 右上 | 「详解」按钮、「斩」按钮 |
| 中间 | **四选一的中文释义题** |
| 下方 | 它在视频里出现的**精确时间点**，如 `▶ 3:47`，**点一下视频跳回去** |
| 卡片外底部 | **常驻**「‹ 上一题」「n / N」「下一题 ›」 |

### 翻页（三种都行）

- **点**底部的「上一题 / 下一题」按钮（一直可见，翻到头会变灰）
- **按**键盘 `←` / `→`
- **划**鼠标（按住卡片左右拖一下）

### 答题

- 选**错** → 那个选项旁立刻出现 **❌** 并变灰，**题目停在原地**，接着选，直到选对
- 选**对** → 选项变绿打勾，下面亮出这个词的中文释义，**约 0.75 秒后自动翻到下一题**

> 所以一整套流程就是：不会就选，选错了继续选，选对了自动往下走。不用点任何「下一题」也能一路做完。

### 回看单词在视频里的位置

- 单词下方每个时间点都可以**点**（带 ▶ 图标），点了视频会跳到那句话
- 时间点记的是**那一句真正出现的秒数**（如 `3:47`），不是整点
- 实际落点会比记录时间**再提前 0.7 秒** —— 因为字幕经常在单词那一瞬间之后就翻走了，正好跳过去常常扑空

### 其它

- 看到熟悉的词，点 **「斩」** → 该词**立刻从题堆里消失**
- 想看得更深，点 **「详解」**（或答对后亮出的那条释义）→ 弹出详情（两阶段加载，本地内容秒出）：
  - **四级释义（常用）**：每个词性只保留前 2 个常用释义，带【古】/(archaic)/(dated)/(rare) 等偏门标记的自动删除
  - **单词变形**：复数 / 第三人称单数 / 过去式 / 过去分词 / 现在分词 / 比较级 / 最高级——**本地计算，秒出**，含约 100 个不规则动词 + 40 个不规则名词复数 + 不规则比较级
  - **各词性释义**：联网查询（主词典 4 秒超时 → 自动切 Wiktionary 兜底，双词典都 404 才放弃，以四级释义为准）
  - **同根词**（四级词表内）

> 重要：本扩展**优先读取「沉浸式翻译」渲染的双语字幕**，所以它不再是"一次性抓完全部字幕"，而是**跟着播放进度实时累积**。你看到一个视频多长时间，就收集多少词。没开沉浸式翻译时，自动退回抓 YouTube 原生字幕。

## 四、几个要点（务必看）

1. **一定要开沉浸式翻译的双语字幕**：本扩展默认监听沉浸式翻译的双语字幕（`#immersive-translate-caption-window`），只取其中的**英文原文**行。它是**唯一稳定的抓词通道，建议一直开着**。全程只读、不修改它的 DOM，不会影响沉浸式翻译的正常显示，也不会影响你看视频。
2. **没开沉浸式翻译会怎样**：会自动退回抓 YouTube 原生字幕轨，所以 **YouTube 上勉强能用**；但 **Netflix / B站 等平台没有原生英文字幕可抓，不开就一定抓不到词**。
3. **实时累积，不是一次性全量**：沉浸式翻译只渲染"当前这一句"字幕，所以单词是边看边收集的。想收集完整个视频的词，就得把视频看完（或快进）。
4. **答题状态在关弹窗后不保留**：本次答对 / 答错的标记只在弹窗开着的时候有效，关掉再开就是干净的题堆。只有「已斩词」是永久保存的。
5. **斩词是全局的**：斩掉一个词，它**立刻从「当前视频」的题堆里消失**，以后所有视频里也不再出现。想恢复去「已斩词」标签页点 ✕。
6. **时间点是精确秒数，每 3 分钟区间最多一个**：一个词在 0:00~3:00 之间出现多少次都只记**最早那一句的时间**（比如 `0:47`），下一个 3 分钟区间再记一个，最多 10 个。这样既不会刷屏，又能真正定位到原句。
7. **记词题全部离线**：4590 个词的题库（正确释义 + 3 个形近/易混的干扰释义）已经打包在扩展里，**出题和判分都在本机，不联网**；发音走系统语音合成，同样不联网。
8. **词形还原**：`studies`/`studying`/`studied` 会匹配到词根 `study`，卡片标题按字幕原样显示，后面用小字标出原型。

## 五、出问题先看这里（按顺序排查）

**症状：popup 里显示「未捕获 / 没产出」。**

1. **扩展刷新过没**：改完代码必须去 `chrome://extensions/` 点扩展的**刷新**按钮。
2. **页面刷新过没**：content script 是页面加载时注入的——改了扩展代码后，**正在看的视频页要 F5 刷新一次**，不然跑的还是旧脚本（新装扩展同理：先装再开页面，或者开了页面后刷新）。
3. **沉浸式翻译的双语字幕开了没** —— **这是最常见的原因**：视频上必须能看到**英文 + 中文两行**字幕。只开了沉浸式翻译但字幕没显示出来，一样抓不到。
4. **视频播了没**：沉浸式翻译只实时渲染"当前这一句"，**单词是跟着播放一句句累积的**。只打开不播、或播几秒就停，popup 里自然没东西。播 30 秒再点图标。
5. popup 会直接告诉你卡在哪一步：
   - **「脚本没在这个页面跑起来」** → 就是第 2 步，刷新页面
   - **「脚本已注入，但还没收到字幕」** → 就是第 3/4 步，开双语字幕 + 继续播

**症状：点时间点没反应。**

- 说明当前标签页不是视频页，或者页面没刷新过（content script 没起来），浏览器地址栏回车刷新一下即可。
- 如果那个时间点是很久以前的老记录（存的还是 `'3:00'` 这种字符串），也能点，会自动换算成秒数。

## 六、词表来源

内置 **4590 个四级词汇**（含中文释义），来源：

1. 开源词库 `github.com/eeliu/english-vocabulary` 的「四级-乱序」表（4538 词，进阶核心词）
2. 手动补充 52 个基础高频词（`study`/`run`/`take`/`write` 等四级必考但原表剔除的基础词）

**题库**：另有 `quiz_bank.json`，为这 4590 个词各准备了 3 个「形近 / 同词性 / 易混淆」的干扰释义（例如 `access` 配 `accent`、`actress`、`accuse`；`clean` 配 `clear`、`clever`、`lean`）。它由 `cet4_words.json` 离线生成并打包在扩展内，**出题不需要联网**。

如果你想要更全的词表，可以自行替换 `cet4_words.json`（格式：`{"word": "释义", ...}`），改完在 `chrome://extensions/` 里点扩展的「刷新」按钮。

**联网查词**：点「详解」时才会调用 [Free Dictionary API](https://dictionaryapi.dev/)（免费、无需 key）获取音标、多词性释义、例句。查不到会自动切 Wiktionary。需要联网。

## 七、已知限制

- 只支持 **字幕**，不支持纯语音识别（语音转文字需要联网 API + 付费，暂不做）。
- 时间点回看依赖 content script 在页面上运行，所以**必须刷新过页面**（装完扩展后的第一次、或改完代码后）。
- 点单词发音依赖**系统自带的英文语音包**（Windows / macOS 都自带）。系统里若没有英文语音则会没声音，但不影响其他功能。
- 第一次打开某个视频可能要等字幕加载完（通常 1~3 秒），没抓到就点「重新抓取」。
