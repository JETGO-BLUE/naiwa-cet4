奶娃过四级 · 安装 & 使用说明

一个 Chrome/Edge 扩展，增量抓取视频字幕里的四级、六级和雅思词汇。可选择单个词库，并在普通模式查词或测试模式练中文四选一；两种模式共享字幕记录、视频历史和已斩词。

字幕来源可为「沉浸式翻译」显示的英文原文、页面可读取的英文 TextTrack，或 YouTube 原生字幕轨。来源与网站不同，读取能力也会不同；字幕匹配在本地完成。

一、安装（3 步）

Chrome：地址栏输入 chrome://extensions/ 回车

Edge：地址栏输入 edge://extensions/ 回车（同一份代码，Edge 直接可用，无需改动）

  1. 打开上面的扩展管理页
  2. 打开 「开发者模式」 开关（Chrome 在右上角，Edge 在左下角）
  3. 点 「加载已解压的扩展程序」，选中你解压出来的那个文件夹 —— 要选到「含 manifest.json 的那一层」，不要选它的上一层

装好后工具栏会出现奶娃头像图标（扩展名：奶娃过四级）。

⚠️ 因为权限覆盖所有网站，加载或更新后浏览器可能提示"已更改权限"，点扩展卡片上的刷新按钮即可。 Chrome 和 Edge 可以同时装同一份，但两边的「已斩词」数据各自独立、不互通。

二、怎么用

  1. 打开有英文字幕的视频；可使用「沉浸式翻译」英文原文或页面提供的可读标准英文字幕轨
  2. 让视频播放，双语字幕一句句出现时，本扩展会边看边自动累积单词
  3. 点工具栏图标，在设置中选择四级、六级或雅思词库，以及普通模式或测试模式。两种模式都会隐藏基础词，模式切换不清空已采集记录。
  4. 单词下方显示字幕中的精确时间点（沿用采集精度，最多到 0.1 秒；每词保留最早的 10 个不同时间点）
  5. 测试模式单击单词可朗读；只使用浏览器标记为本地服务的英语音色，没有可用音色时会提示。
  6. 从 4 个中文释义里选一个：
    • 选错 → 那个选项旁立刻出现 ❌，可以接着选，直到选对
    • 选对 → 显示正确释义并完成本次题目；答对不会自动标记为熟悉词
  7. 看到熟悉的词，点右边的 「斩」 → 该词立刻从当前列表消失
  8. 普通模式点击单词，或测试模式点击 「详解」 → 弹出详情（两阶段加载，本地内容秒出）：
    • 本地词表释义（如有）：每个词性只保留前 2 个常用释义，带【古】/(archaic)/(dated)/(rare) 等偏门标记的自动删除
    • 单词变形：复数 / 第三人称单数 / 过去式 / 过去分词 / 现在分词 / 比较级 / 最高级——本地计算，秒出，含约 100 个不规则动词 + 40 个不规则名词复数 + 不规则比较级
    • 各词性释义：联网查询（主词典 4 秒超时 → 自动切 Wiktionary 兜底，双词典都 404 才放弃，以四级释义为准）
    • 同根词（内置词表内）
重要：本扩展优先读取「沉浸式翻译」渲染的双语字幕，所以它不再是"一次性抓完全部字幕"，而是跟着播放进度实时累积。你看到一个视频多长时间，就收集多少词。没开沉浸式翻译时，自动退回抓 YouTube 原生字幕。

三、界面说明

标签页作用
当前视频当前词库和学习模式的单词卡/题卡与时间点，可搜索、可斩词
历史记录按所选词库回看视频词汇，可删除单条记录；当前页面关联的记录暂不能删除
已斩词所有被你「斩」掉的熟悉词，可撤销、可清空

四、几个要点（务必看）

  1. 沉浸式翻译通道：页面出现双语字幕时读取其英文原文行；只读观察字幕，不修改页面 DOM。
  2. 其他字幕来源：页面提供可读且启用的标准 TextTrack 时按字幕事件增量读取。YouTube 还可通过原生字幕兜底请求整条字幕轨，可能提前包含尚未播放的内容。不同网站和字幕轨的可读取性不同。
  3. 实时累积，不是一次性全量：沉浸式翻译只渲染"当前这一句"字幕，所以单词是边看边收集的。想收集完整个视频的词，就得把视频看完（或快进）。
  4. 斩词是全局的：斩掉一个词，它立刻从「当前视频」列表里消失，以后所有视频里也不再出现。想恢复去「已斩词」标签页点 ✕。
  5. 时间点最多 10 个：每词保留最早的 10 个不同时间点，精度沿用字幕来源，标准字幕轨可精确到 0.1 秒。
  6. 记词题在本机：题库覆盖三词库词头并集 6,043 词；保留上游 4,590 道四级题，另有 1,453 道根据公开释义整理的补充题。补充题由程序生成，尚未逐题人工语义审校；查看扩展「词表来源」页了解许可与来源。没有题目时仍可点击「详解」。
  7. 朗读只使用本地英语音色：没有可用本地音色时会显示提示，答题不受影响。
  8. 词形还原：studies/studying/studied 会匹配到词根 study，列表按字幕原样显示。

五、出问题先看这里（按顺序排查）

症状：popup 里显示「未捕获 / 没产出」。

  1. 扩展刷新过没：改完代码必须去 chrome://extensions/ 点扩展的刷新按钮。
  2. 页面刷新过没：content script 是页面加载时注入的——改了扩展代码后，正在看的视频页要 F5 刷新一次，不然跑的还是旧脚本（新装扩展同理：先装再开页面，或者开了页面后刷新）。
  3. 沉浸式翻译的双语字幕开了没 —— 这是最常见的原因：视频上必须能看到英文 + 中文两行字幕。只开了沉浸式翻译但字幕没显示出来，一样抓不到。
  4. 视频播了没：沉浸式翻译只实时渲染"当前这一句"，单词是跟着播放一句句累积的。只打开不播、或播几秒就停，popup 里自然没东西。播 30 秒再点图标。
  5. popup 会直接告诉你卡在哪一步：
    • 「脚本没在这个页面跑起来」 → 就是第 2 步，刷新页面
    • 「脚本已注入，但还没收到字幕」 → 就是第 3/4 步，开双语字幕 + 继续播

六、词表来源

内置 4590 个四级词汇（含中文释义），来源：

  1. 开源词库 github.com/eeliu/english-vocabulary 的「四级-乱序」表（4538 词，进阶核心词）
  2. 手动补充 52 个基础高频词（study/run/take/write 等四级必考但原表剔除的基础词）

题库：上游四级题库 quiz_bank.json 保留原样；quiz_extras.json 补足三词库并集的题目。缺失词释义来自固定版本的 ECDICT；干扰项由脚本按词性和释义差异整理。IELTS 旧词头 inasmuchas 兼容字幕短语 inasmuch as，释义根据固定版本 Wiktionary 英文义项整理。补充题未经逐题人工语义审校，来源、许可、版本和哈希见扩展「词表来源」页及 quiz-sources.json。出题不需要联网。

如果你想要更全的词表，可以自行替换 cet4_words.json（格式：{"word": "释义", ...}），改完在 chrome://extensions/ 里点扩展的「刷新」按钮。

联网查词：点「详解」时才会调用 Free Dictionary API（免费、无需 key）获取音标、多词性释义、例句。查不到会自动切 Wiktionary。需要联网。

七、已知限制

  • 只支持 字幕，不支持纯语音识别（语音转文字需要联网 API + 付费，暂不做）。
  • 时间点为文字展示（mm:ss），不做点击跳转。
  • 测试模式发音依赖可用的本地英语音色；扩展不会选择远程音色，没有可用本地音色时会提示。
  • 第一次打开某个视频可能要等字幕加载完（通常 1~3 秒），没抓到就点「重新抓取」。
