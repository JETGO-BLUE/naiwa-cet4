# 合并修复验证（1.6.2）

修改目录为 `yt-cet4-extension`，保留原版根目录。卡片、自动翻页、回看和自定义词库继续使用；普通/测试模式共用一份原始记录。

## 数据与采集

- 同视频的字幕处理和删除串行；整轨也只合并，成功落盘后才发送保存确认。
- 页面保留未确认事件，后台重启或失败后重发；多次失败时提示保留待保存数据，重新抓取可重试。
- 旧字符串时间点（含小数）可解析，不因新字幕被当作无效数值清掉。
- 可靠 YouTube ID 继续累加；身份不可靠的页面独立建档并标记未确认，不自动猜测旧记录归属。
- 标准 TextTrack、沉浸式字幕容器重连和原生字幕身份校验均有回归检查。

## 进度与界面

- 答题进度保存全部已知词的状态；后台按增量合并，搜索/词库筛选不删除其他词的状态。
- 翻页立即提交位置；切视频前等待保存，异步渲染与查词只写回仍然对应的界面。
- 自定义词库变化后重新标注分类并清理题目缓存；题目选项变化时清除旧答题下标。
- 弹窗监听视频记录变化，新增词卡后保持当前词；历史浏览不被其他视频打断。
- 词库按钮在空态也可用；状态条固定单行；朗读仅选择本地英语音色。
